- **带租户头 → `{"code":500,"msg":"系统繁忙..."}`** ❌ 期望 404

### 新发现的 Bug（P1）
`NoResourceFoundException`（Spring 6.1 无 Controller/静态资源 404 抛的异常）被 `@ExceptionHandler(Exception.class)` 兜底捕获 → 所有 404 变成 500。
修法：GlobalExceptionHandler 增加 `@ExceptionHandler(NoResourceFoundException.class)` → R.fail(404, "接口不存在")。

### 设计取舍待定
所有异常 HTTP 状态码恒为 200，code 只在 body。影响：网关/压测/SkyWalking 按 HTTP 统计错误率会恒为 0。
建议 Step 5 一起改成 ResponseEntity 让 HTTP 跟随 code，或明确保持 200 并在网关层按 body.code 统计。

### 小隐患
`handleValidException` 用 `getFieldErrors().get(0)`，列表为空时 IndexOutOfBounds。建议用 `getFieldError()` 判空。
