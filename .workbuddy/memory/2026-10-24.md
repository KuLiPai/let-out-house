### 新问题：实体审计字段命名导致全表查询失败
```
Unknown column 'update_by' in 'field list'
SELECT id, ..., created_by, created_at, update_by FROM agent_config WHERE id=? AND deleted=0 AND tenant_id=1
```
实体 `private Long updateBy;` → MP 驼峰转列名得 `update_by`，而表列是 **`updated_by`**（多个 d）。
因为 `selectById` 会带上该列，**详情、更新、列表全部 500**。

对比：`private Long CreatedBy;` / `CreatedAt` 反而能映射到 `created_by`/`created_at`
—— 因为 MP 的 camelToUnderline 对 i=0 的大写字母不插入下划线，属"侥幸正确"。

### 修法
- 实体三字段统一改为标准小写驼峰：`createdBy` / `createdAt` / **`updatedBy`**
- Service 里 `patch.setUpdateBy(...)` → `setUpdatedBy(...)`
- 不要依赖首字母大写的侥幸映射
