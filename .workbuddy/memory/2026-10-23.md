## 审查 DTO + Entity（登录接口 01:07）

编译通过（12 sources SUCCESS），但有必须修的问题。

### P0
- **`SysRole` 三个注解全缺**：无 `@Data`（getter 不存在，Service 一调用就编译失败）、无 `@TableName`（靠类名驼峰推导侥幸对）、无 `@TableId(AUTO)`（默认雪花 ID）

### P1
- `LoginResponse` 上用了 `@TableField(value="real_name")` 和 `@NotBlank` —— 概念错误：
  - `@TableField` 是 ORM 注解，只对 Entity 生效，DTO 不在映射链路里，完全无效
  - `@NotBlank` 是入参校验，出参永远不校验；且 token 是字符串，"不可为0"的 message 说明误解
- `SysUser` 缺 `lastLoginAt`（`last_login_at` 列存在，登录成功要更新）

### P2
- `Tenant` 的 `@TableName()` 空括号，应显式 `@TableName("tenant")`
- `LoginRequest` 的 tenantCode/username 缺 `@Size(max=64)`
- 多余 import：LoginRequest 的 NotNull；LoginResponse 的 TableField/NotBlank

### 做对的
- SysUser：有 `deleted`、无 `tenantId` —— 核心约束守住
- 三实体均 implements Serializable
- 未声明 created_at/updated_at 等审计字段，符合 MVP 取舍
